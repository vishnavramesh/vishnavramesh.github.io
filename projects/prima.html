Prima — Longitudinal Disease Progression

PyTorch·MLNeurosurg Lab, University of Michigan·Jul – Aug 2026

Lab repo on GitHub ↗ MLNeurosurg Lab ↗

The problem

Prima is a health-system-scale brain-MRI vision–language model. It reads a single scan well — but disease is a process, not a snapshot. Radiologists compare a patient's scans over time; the model couldn't.

What I built

  • A longitudinal module that models disease progression across sequential scans of the same patient, extending Prima's single-scan representations into a temporal one.
  • The custom PyTorch dataset, model architecture, and training pipeline (400+ lines) that pair and order patient scans for training.
  • Memory-mapped checkpoint loading so the pipeline handles Prima's large weights efficiently on shared lab hardware.

Context

This work landed in an active research codebase tied to a paper on health-system-scale neuroimaging models — real code review, real reproducibility constraints, real data governance.
