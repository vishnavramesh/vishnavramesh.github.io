The problem

Blueprints for Pangaea redistributes surplus medical supplies from US hospitals to under-resourced clinics abroad. Inventory across chapters lived in shared spreadsheets: no integrity guarantees, no audit trail, fuzzy duplicate item names, and every lookup was a manual scan.

What I built

  • A BCNF-normalized PostgreSQL schema with a trigger-maintained transaction ledger — every stock movement is an immutable ledger row, so current quantities are derived, not hand-edited.
  • Trigram/GIN fuzzy-search indices for item matching, so "gauze 4x4 sterile" and "sterile 4×4 gauze pads" resolve to the same item.
  • A multithreaded C++ HTTP service (Drogon + libpqxx) serving inventory as JSON and syncing live dashboard feeds.
  • Deduplication plus automated integrity checks: negative stock, expired items, and unverified requests are flagged before they hit the ledger.

Results

Backend latency fell from roughly 1.2 seconds to ~40 milliseconds, and the system is rolling out nationwide to 14 university chapters, replacing the spreadsheet workflow entirely.
